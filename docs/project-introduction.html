03 / ARCHITECTURE
Agent reasoning
Discovery agent

Searches and inspects catalog candidates through constrained, typed tools.

Modeling agent

Creates or modifies OpenSCAD from a versioned, immutable handoff.

Material assignment agent

Selects from server-filtered compatible spools, slots, and toolheads.

Agents do not receive shell, arbitrary filesystem, printer-control, or shared chat history.
Durable orchestration
FastAPI workflow engine

Coordinates states, retries, typed handoffs, approvals, and idempotent operations.

SQLite + immutable artifacts

Persists workflow history, configuration revisions, manifests, and exact digests.

Human gates

Approve the model, confirm materials, review the slice, and authorize Print/Send.

Fail-closed recovery

Invalid candidates, stale snapshots, mapping drift, and slicer errors create explicit revisions.

Deterministic services
Geometry pipeline

OpenSCAD, trimesh, lib3mf, unit normalization, multipart packaging, and mesh checks.

Printer configuration

Versioned H2D profile plus read-only cloud device, nozzle, AMS, and quantity snapshots.

Bambu Studio CLI

Deterministic slicing with pinned profiles and strict output reconciliation.

Official Bambu Connect

Owns signed-in transfer, printer selection, and final physical action.

Three reasoning roles, one durable state machine Typed tools   |   Canonical hashes   |   Explicit authority
The architecture deliberately separates ambiguity from authority. Agents reason about discovery, modeling, and assignment. Application code owns geometry checks, state, evidence, and integration. Discovery and modeling cannot influence each other except through the immutable handoff.

Challenges and lessons

Software meets messy geometry and real hardware.

05 / LEARNINGS
01

Geometry truth

STL files are unitless. Scale, orientation, manifoldness, tiny features, and slicer behavior all need independent verification.

02

Multipart identity

Part names and repeated instances must survive catalog import, 3MF conversion, arrangement, slicing, and output validation.

03

Physical materials

A requested color must reconcile with real AMS slots, filament profiles, remaining quantity, nozzles, and dual toolheads.

04

Safe integration

Desktop authentication, proprietary slicer behavior, cloud snapshots, retries, and final hardware authority need strict boundaries.
